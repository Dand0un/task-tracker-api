Due dates + overdue filter 
---------------------------


| **ID**   | **User Story**                                                                                                                         | **Acceptance Criteria**                                                                                                                                                                                                                                                                                                                                                                                                             |
| -------- | -------------------------------------------------------------------------------------------------------------------                    | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **US-1** | **As a team member, I want to add a due date to a task, so that I know when the task is expected to be completed.**                    | 1. **Given** a valid date, **when** I create a new task or update an existing task, **then** the due date is saved with the task.<br><br>2. **Given** a task with a due date, **when** I retrieve the task, **then** the due date is included in the response.<br><br>3. **Given** an invalid date format, **when** I attempt to save the task, **then** the API returns a validation error and the task is not created or updated. |
| **US-2** | **As a team member, I want to view whether a task is overdue, so that I can quickly identify tasks that require immediate attention.** | 1. **Given** a task whose overdue date is earlier than the current date and whose status is not **Done**, **when** I view the task, **then** it is marked as overdue.<br><br>2. **Given** a task whose overdue date is today or in the future, **when** I view the task, **then** it is not marked as overdue.<br><br>3. **Given** a task with no overdue date, **when** I view the task, **then** it is not marked as overdue and no error is returned. |
| **US-3** | **As a team member, I want to filter tasks by overdue status, so that I can focus on tasks that require immediate action.**            | 1. **Given** I request overdue tasks, **when** overdue tasks exist, **then** only tasks currently marked as overdue are returned.<br><br>2. **Given** there are no overdue tasks, **when** I apply the overdue filter, **then** an empty list is returned with a successful response.<br><br>3. **Given** an invalid value for the overdue filter, **when** I submit the request, **then** the API returns a validation error.                           |

| **US-1** | **As a team member, I want to search tasks by title, so that I can quickly find a specific task.**                                                               | 1. **Given** a search keyword that matches one or more task titles, **when** I request `GET /tasks?search=<keyword>`, **then** only the matching tasks are returned.<br><br>2. **Given** a search keyword that matches no task titles, **when** I perform the search, **then** the API returns an empty list with a successful response.<br><br>3. **Given** an empty or whitespace-only search query, **when** I submit the request, **then** the API ignores the search parameter and returns all tasks matching any other supplied filters.                                             |

| **US-3** | **As a team member, I want to combine title search with one or more filters, so that I can efficiently locate specific tasks that satisfy multiple conditions.** | 1. **Given** a title search keyword and one or more valid filters (status, priority, assignee, and/or overdue status), **when** I request `GET /tasks`, **then** only tasks matching both the search keyword and all specified filters are returned.<br><br>2. **Given** no task matches both the title search keyword and the selected filters, **when** I perform the request, **then** the API returns an empty list with a successful response.<br><br>3. **Given** an invalid search or filter parameter, **when** I submit the request, **then** the API returns a validation error. |

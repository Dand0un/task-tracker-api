# My Personal AI Usage Rules

## Rule 1 – What I will never paste
- Production credentials (passwords, API keys, tokens, certificates, private keys)
- Customer or employee personal data (PII)
- Client confidential information or internal documents without permission
- Production database dumps or sensitive log files
- Anything covered by an NDA or confidentiality agreement


## Rule 2 – What I will always verify before accepting
I understand every line of generated code before merging it.
- I can explain why the solution works and the trade-offs it makes.
- The code compiles and all relevant tests pass, and also break when i change the code on purpose.
- The implementation actually solves the requirement—not just something that looks plausible.
- Security, performance, and edge cases have been considered.
- The code follows our team's coding standards and architecture.

## Rule 3 – How I will record AI contributions
- Mention AI assistance in the PR description when it significantly contributed.
- Review and edit all AI-generated code before committing.
- Keep only the code I fully understand and can maintain.
- Document any important design decisions that originated from AI suggestions.
- Never attribute responsibility to AI—the final code is my responsibility.
